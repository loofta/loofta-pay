## Usage

- Drop the SVG in an <img>, inline it, or use as a CSS background.
- Sticker-border look: CSS `filter: drop-shadow(2px 0 0 #fff) drop-shadow(-2px 0 0 #fff) drop-shadow(0 2px 0 #fff) drop-shadow(0 -2px 0 #fff);`
- Pair names/captions with Clash Display (headings) and Clash Grotesk (body).
