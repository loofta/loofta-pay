# 🚀 Loofta

Welcome to **Loofta**! This project is a mini Telegram app built on the TON blockchain network using **Next.js** and **Firebase**. Loofta aims to provide a seamless experience for interacting with the decentralized web directly through Telegram. 🌐💬

## 📋 Project Overview

Loofta leverages the power of the **TON blockchain** for decentralized transactions and storage, while using **Next.js** for the frontend and **Firebase** for real-time database and authentication. This combination ensures a fast, secure, and scalable application.

## 🛠️ Tech Stack

- **Next.js**: The React framework for building user interfaces.
- **Firebase**: A platform for building web and mobile applications, offering real-time databases, authentication, and cloud functions.
- **TON Blockchain**: A decentralized network for fast and secure transactions.
